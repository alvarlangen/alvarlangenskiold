# Data sources

All files in this folder (and `public/data/`, `public/flags/`) are generated by the scripts in `/scripts`
and committed to the repository. Nothing is fetched at runtime. Fetch date: **2026-10-23**.

| Data                                                                                   | Source                                                                                                                         | License       | Script                                |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ------------- | ------------------------------------- |
| Country names, ISO codes, regions, languages, currencies, land borders, area, capitals | [world-countries](https://github.com/mledoze/countries) v5.1 (npm)                                                             | ODbL 1.0      | `build-countries.mjs`                 |
| Country geometry (pieces, world background)                                            | [Natural Earth](https://www.naturalearthdata.com/) 1:10m / 1:50m via [world-atlas](https://github.com/topojson/world-atlas) v2 | Public domain | `build-pieces.mjs`, `build-world.mjs` |
| Country population estimates (ranking only, not shipped)                               | Natural Earth 1:10m admin-0 `POP_EST`                                                                                          | Public domain | `build-countries.mjs`                 |
| Flag colors and flag images                                                            | [flag-icons](https://github.com/lipis/flag-icons) v7                                                                           | MIT           | `build-flags.mjs`                     |
| Cities: coordinates, decoy towns, population (ranking only, not shipped)               | [GeoNames](https://www.geonames.org/) cities1000 via [all-the-cities](https://www.npmjs.com/package/all-the-cities)            | CC BY 4.0     | `build-cities.mjs`                    |
| City list, English display names, exonyms, facts                                       | Hand-curated (`scripts/data/cities-curated.mjs`)                                                                               | —             | —                                     |
| Country facts                                                                          | Hand-written (`country-facts.json`)                                                                                            | —             | —                                     |

Population is used only to compute `rank` (difficulty) and is never written to the shipped JSON.
