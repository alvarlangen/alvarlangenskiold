# Data sources

All files in this folder (and `public/data/tiles/`, `public/flags/`, `public/imagery/`) are generated by the scripts in
`/scripts` and committed to the repository. Nothing is fetched at runtime. Fetch date: **2026-10-23**.

| Data                                                                                   | Source                                                                                                              | License       | Script                |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | ------------- | --------------------- |
| Country names, ISO codes, regions, languages, currencies, land borders, area, capitals | [world-countries](https://github.com/mledoze/countries) v5.1 (npm)                                                  | ODbL 1.0      | `build-countries.mjs` |
| Map tiles: land, lakes, rivers, urban areas, roads, railways, borders                  | [Natural Earth](https://www.naturalearthdata.com/) 1:10m GeoJSON                                                    | Public domain | `build-tiles.mjs`     |
| Country geometry for "nearest across the sea"                                          | Natural Earth via [world-atlas](https://github.com/topojson/world-atlas) v2                                         | Public domain | `build-countries.mjs` |
| Country population estimates (ranking only, not shipped)                               | Natural Earth 1:10m admin-0 `POP_EST`                                                                               | Public domain | `build-countries.mjs` |
| Flag colors and flag images                                                            | [flag-icons](https://github.com/lipis/flag-icons) v7                                                                | MIT           | `build-flags.mjs`     |
| Cities and towns on the map; population (ranking only, not shipped)                    | [GeoNames](https://www.geonames.org/) cities1000 via [all-the-cities](https://www.npmjs.com/package/all-the-cities) | CC BY 4.0     | `build-cities.mjs`    |
| City list, English display names, exonyms, facts                                       | Hand-curated (`scripts/data/cities-curated.mjs`)                                                                    | —             | —                     |

Satellite imagery (`public/imagery/`) is made by `scripts/build-imagery.py` from the
[ESA WorldCover](https://esa-worldcover.org/) Sentinel-2 RGBNIR yearly median composite 2021 (10 m), read from the
public AWS bucket `esa-worldcover-s2`. License: CC BY 4.0. Attribution: © ESA WorldCover project / Contains modified
Copernicus Sentinel data (2021) processed by ESA WorldCover consortium. Colours are adjusted and water is recoloured.
An online provider can be configured instead with `VITE_MAP_PROVIDER` (see README, "Satellite imagery").

Population is used only to compute `rank` (difficulty) and is never written to the shipped JSON.
